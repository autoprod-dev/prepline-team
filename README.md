# Prepline team edition (v3.3.2)

Prepline by Autoprod: sorts a kitchen preplist into prep lists by dish, station and team section.
This is the team edition: every tool is on, there is no licence or account.

Open it at https://autoprod-dev.github.io/prepline-team/

- Everything (pdf.js, SheetJS, the QR code library) is served from this site. No CDN, no web fonts,
  no request to any other domain. Your lists stay in your browser.
- After the first visit it keeps working offline (installable app, service worker scoped to /prepline-team/).
